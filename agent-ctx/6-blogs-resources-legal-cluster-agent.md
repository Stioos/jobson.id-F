## Key Decisions:
- **Shared PublicLegalPage component** (`PublicLegalShared.tsx`): Created a reusable template that all 4 legal pages (Terms, Privacy, Refund, Placement Policy) consume via props. This avoids duplicating the hero + quick-nav + section-cards + CTA pattern 4 times. Each legal page file is now ~90 lines (just the SECTIONS data + a one-line `<PublicLegalPage ... />` call) instead of ~250 lines. Total savings: ~600 lines of code.
- **react-markdown for blog content** (`PublicBlogDetail.tsx`): Used react-markdown v10.1.0 (already in package.json) with a custom `components` map that overrides h1/h2/h3/p/ul/ol/li/a/strong/blockquote/code with our own Tailwind-styled versions. This avoids the dependency on `@tailwindcss/typography` (which isn't installed) while giving us full control over typography. The blog content data uses standard markdown (`### Heading`, paragraphs, lists) which renders cleanly.
- **Interactive calculators** (`PublicBecomeSalesAgent`, `PublicPartnerWithUs`): Both use `React.useState` for interactive earnings/revenue calculators. Sales agent calculator: monthlySales (input) + tier (Silver/Gold/Platinum buttons) → monthly + annual commission (₹ Lakhs format). Partner calculator: dealsPerMonth (input + range slider) + avgDealSize (input) + share % (5 preset buttons 10/15/20/25/30) → monthly + annual revenue.
- **Apply forms** (`PublicBecomeSalesAgent`, `PublicBecomeTechConsultant`): Both use `React.useState` for form state + a manual onSubmit handler that validates email format + shows toast.success on submit. No react-hook-form / zod to keep these forms lightweight (the form has 5 fields, doesn't need RHF). The smooth-scroll to #apply anchor uses `document.getElementById('apply')?.scrollIntoView({ behavior: 'smooth' })`.
- **Featured spotlight only on All category** (`PublicBlogs.tsx`): The featured 3-card spotlight only renders when category is "All" AND search query is empty — so users see the spotlight by default, but it disappears when they're filtering/searching (to avoid duplicate posts in the grid).
- **Pagination via "Load More"** (`PublicBlogs.tsx`): Page size 9, visibleCount state that increases by 9 on each Load More click. Reset to 9 when category or search changes (via useEffect). Shows "Load more articles" button only when hasMore is true.
- **Table of contents sidebar** (`PublicBlogDetail.tsx`): Auto-extracts H2/H3 headings from the markdown content using a regex on the raw content string (`/^#{2,3}\s+(.+?)\s*$/`). Shows up to 6 headings as anchor links in a sticky sidebar (hidden on mobile, shown on lg+). Also includes a mini newsletter signup card below the TOC.
- **Share buttons** (`PublicBlogDetail.tsx`): Twitter → `window.open('https://twitter.com/intent/tweet?text=...&url=...')`. LinkedIn → `window.open('https://www.linkedin.com/sharing/share-offsite/?url=...')`. Copy link → `navigator.clipboard?.writeText(window.location.href)` + toast.success/error. All use `_blank, noopener,noreferrer` for security.
- **Per-card accent colors as SECONDARY accents only** (Sales Agent tiers, Tech Consultant tiers, Industries, Partnership models): Used inline `style={{ borderTopColor: color, borderTopWidth: 4 }}` for top borders and `style={{ backgroundColor: ${color}1A, color: color }}` for icon tiles. Primary CTAs always use the emerald `bg-brand` / `text-brand`. The "featured" tier (Gold/Silver for sales, Senior for consultant, Channel Partner for partnership) gets `border-brand` + a top color bar + a "Most popular" badge instead of a colored top-border — keeping emerald as the visual anchor.
- **Realistic Indian market data**: ₹ LPA / Lakhs format throughout. Indian names, cities, companies (TCS, Infosys, Wipro, Flipkart, Swiggy, Razorpay, Zerodha, FinEdge, MediCare, RetailMax, ScaleKit). Indian legal references (DPDP Act 2023, Consumer Protection Act 2019, Industrial Employment Standing Orders Act, Payment of Wages Act). Bengaluru HQ address.
